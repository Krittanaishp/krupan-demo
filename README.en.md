# Office supplies & asset register (demo)

[ภาษาไทย](README.md)

A web app for the supplies and asset-register work of a Thai district office, built during an internship.
It runs on the office LAN and works on desktop and mobile. The UI is in Thai.

> **This repo is a demo with fictional data only.** The office name ("ที่ว่าการอำเภอตัวอย่าง", "Example District Office"),
> people, rooms, registration numbers (`ปค.99-9999-…`), prices and supply items are all generated by
> `scripts/seed_demo.py`.

**Features**
- **Consumable supplies:** items with base and bulk units, receipts and department issues with approver.
  Balances are always computed from movements and can never go negative, including as-of-date balances.
  Low-stock warnings, stock card, monthly summaries, Excel export of every table, Excel import with a preview.
  Item picker with typo-tolerant Thai search.
- **Asset register:** search and filters, rooms and holders, moves, repairs, disposals, review queue,
  annual stock check, government-style printable reports.
- **Everywhere:** three roles (admin / editor / viewer) and an audit log of every change and export.
  Filters apply instantly and keep the URL in sync, and still work without JavaScript. Tables become cards on small screens.

**Stack:** Python 3.12, FastAPI, Jinja2, htmx, SQLite. No build step and no JS framework. All static files are
served locally (no CDN). Tested with pytest, Playwright and a layout audit at widths 390–1920px.

## Run the demo

Requires [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run python scripts/seed_demo.py      # creates .env with a fresh secret key + data/krupan.db with fictional data
uv run uvicorn app.main:app --port 8000 --no-server-header
```

Open http://127.0.0.1:8000 and sign in:

| user | password | role |
|---|---|---|
| `admin` | `demo-admin-2569` | admin |
| `editor` | `demo-editor-2569` | editor |
| `viewer` | `demo-viewer-2569` | read-only |

> **Warning:** these passwords are public and meant for the fictional demo data only. Before using the app with real data
> or letting other people in, change every password, or seed with `uv run python scripts/seed_demo.py --reset --production`,
> which forces every account to set a new password at first sign-in.

Tests: `uv run --with playwright pytest`. The browser tests use Microsoft Edge and are skipped if Playwright is not installed.

Screenshots are in [docs/screenshots](docs/screenshots).
